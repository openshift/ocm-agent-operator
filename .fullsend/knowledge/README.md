# Knowledge

Repository-specific knowledge and context for FullSend agents.

## Purpose

This directory contains domain knowledge, organizational context, and project-specific
information that agents can reference to make better decisions.

## Contents

Examples of what to place here:
- **Architecture docs**: System design, component relationships
- **Domain knowledge**: Business logic, domain models, terminology
- **Decision records**: ADRs, architecture decisions
- **Runbooks**: Operational procedures, troubleshooting guides
- **Org context**: Team structure, escalation paths, on-call info

## Usage

FullSend agents can access files in this directory to understand:
- Why certain patterns exist
- Historical context for decisions
- Domain-specific constraints
- Operational knowledge

## Format

Prefer Markdown (`.md`) for human-readable knowledge documents.
